Easy Gantt - quick guide

Tasks

  • + Task (or Insert) adds a task below the selected row.
  • Click a cell and type, or double-click it, to edit. Enter saves, Esc cancels, Tab moves right.
  • Durations accept 5, 5d, 2w. A duration of 0 makes a milestone ◆.
  • Typing a Start date pins the task to "start no earlier than" that date (shown with 📌).
  • Double-click a row or bar for the full Task details window.
  • ✓ Done marks the selected tasks 100% complete (shown green with a ✓). Selecting a summary marks all of its subtasks. You can also type any value in % Done for partial progress.

Parent / child (summary) tasks

  • Indent makes a task a child of the task above it. The parent becomes a summary task.
  • Summary rows roll up start, finish, duration, % done, hours and cost from their children.
  • Row 0 is the project summary with totals for the whole project.
  • Click ▾ to collapse or expand a summary.

Estimate and Actual modes

  • Use the Estimate / Actual switch at the top left.
  • Estimate: plan duration, headcount, hours and cost. Enter either headcount or hours and the other is calculated: hours = days × hours per day × headcount (20 days × 8 h × 2 people = 320 h).
  • Actual: record actual start and finish dates, hours and cost. Variance columns show what is over (red, +) or under (green, −) the estimate. On the chart, the grey line is the estimate and the colored bar is what really happened.
  • Entering an actual finish marks the task 100% done.

Holidays and working days

  • No work is scheduled on weekends (if skipped) or holidays. Durations count working days only, so a task that crosses a holiday finishes a day later.
  • The 11 US federal holidays are on by default. Use Calendar… to turn them on or off, add optional or company holidays, and set the hours in a work day.
  • Holidays are shaded on the chart; hover one to see its name.

Resource groups and colors

  • Give each task a resource group (e.g. Sim, Software, GNC, Hardware) and its bar is drawn in that group's color. Tasks without a group are light blue.
  • Type a group name in the Resource column (a new name creates the group), pick one in Assign resource for all selected rows, or use Task details. Assigning a summary assigns all of its subtasks.
  • Resources… sets each group's name and color and shows its tasks, hours and cost. The legend at the bottom left opens it too.

Trace and walk the critical path

  • Walk critical path opens a pop-out Gantt of only the critical tasks. Step through them with Prev/Next (or the arrow keys).
  • Trace… (or the button in Task details) shows just the selected task's predecessors, successors, both, or its driving path: the chain of links that actually sets its start date.
  • Links on a summary count for everything inside it. Tick Direct links only to see one step either way.
  • Double-click a row (or press Trace from here) to trace from that task instead. Show in main chart selects it in the main view.

Critical path

  • Tasks with zero slack (float) are critical: their bars get a red outline and their links turn red. Delaying them delays the whole project.
  • The Slack column shows how many working days a task can slip without moving the finish date.

Dependencies

FS - Finish-to-Start
B can't start until A finishes. The most common link.
SS - Start-to-Start
B can't start until A starts.
FF - Finish-to-Finish
B can't finish until A finishes.
SF - Start-to-Finish
B can't finish until A starts (e.g. hand-over shifts).

Three ways to link tasks

  1. Drag on the chart: hover a bar, drag from a round handle at its start or end onto another bar's start or end half. The type is chosen from the ends you connect.
  2. Toolbar: select rows with Ctrl/Shift-click, pick a type, press Link (Ctrl+L).
  3. Predecessors column: type row numbers, e.g. 3, 3SS, 2FS+2d, 4FF-1d.

Click a link arrow on the chart to change its type or lag, or delete it.
